# Dark Star Orchestra

Dark Star Orchestra (DSO) is a long-running Grateful Dead tribute project. Their own site describes performing complete shows drawn from the Grateful Dead’s history (“recreated” nights).

## In DeadSet

When a tribute setlist lines up with a catalog GD date, Show Detail can offer a recreation link and side-by-side comparison (Phase 4). Upcoming DSO dates appear in the Live tab only when a live API (Bandsintown / Ticketmaster) returns them — never from a hard-coded fake schedule.
